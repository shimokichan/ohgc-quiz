# OHGC — Otaku Creator Archetype Quiz

The official Otaku Hot Girls Club creator archetype quiz.

## Before you deploy

Open `src/App.jsx` and find these two lines near the top:

```
const BEEHIIV_SUBSCRIBE_URL = "https://your-beehiiv-subscribe-url.com";
const IDEA_BANK_SHOP_URL = "https://your-shop-url.com";
```

Replace them with your actual URLs.

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import this repo
3. Click Deploy
4. Done — your quiz is live
